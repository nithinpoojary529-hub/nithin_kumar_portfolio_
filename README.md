## 🌐 Deploying to GitHub Pages or Vercel

### Option 1: GitHub Pages
1. Initialize git and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of developer portfolio"
   git remote add origin https://github.com/nithinpoojary529-hub/nithin-kumar-portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository, go to **Settings > Pages**.
3. Under **Build and deployment > Source**, select `Deploy from a branch` and choose `main` / `root`.
4. Your website will be live in moments!

### Option 2: Vercel
1. Install Vercel CLI (`npm i -g vercel`) or visit [vercel.com](https://vercel.com).
2. Import the GitHub repository or run `vercel` in this folder.
3. Your portfolio is deployed with instant SSL and global CDN!
